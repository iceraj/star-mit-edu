Dear User,

It was brought to our attention that there are issues in running signed Java Application on Mac 10.8+ due to the changes that Apple introduced in signing the software. We have applied to apple developer program during August 2013, but we are still not enrolled into the program. This is entirely our fault as we should have done so months ago to ensure best experience for all our users.

At this stage there is Apple endorsed workaround to ensure that you can still use our software, here are the links:

Apple official KB:http://support.apple.com/kb/HT5290

YouTube guide:http://www.youtube.com/watch?v=GmU6n925y-A

As well as other IT departments facing same issue:http://its.uiowa.edu/support/article/4038

To run Star software please download zip distribution, and disable gatekeeper as specified above. WebStart will unfortunately not work for the time being.

We would like to apologize for inconvenience and we are looking upon approval to join Apple Developer program we will work toward signing apple distribution with Gatekeeper certificate. In the meantime, please accept our apologies.


StarGenetics Developer Team
