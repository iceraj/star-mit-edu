StarMolsim Tools on NanoHUB.org

The StarMolsim tools are hosted on nanohub.org. Below is a list of links to the StarMolsim tools migrated to nanohub.org:

  • stretchfcc - simulates a continuous expansion of an FCC crystal while measuring the energy, stresses, etc
  • deformnanowire - simulates tensile deformation of a copper nanowire
  • crackprop - models supersonic crack propagation in a 2D triangular lattice
  • stretchmol - stretching simulation of an alpha-helical protein domain
  • tad - temperature-accelerated dynamics simulation
  • atomic scale modeling toolkit - this set of simulation tools provides students with the fundamentals of computational problem-solving techniques that are used to understand and predict properties of nanoscale systems.
