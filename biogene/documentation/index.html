Logging in to StarBiogene

  1. Open a web browser and navigate to: http://web.mit.edu/star/biogene. Click on the “Start Biogene” button.
  2. Login to StarBiogene by typing in your email address and clicking the “sign-in” button.
  3. NOTE: The page that loads after this step is the front page of StarBiogene

Using StarBiogene

  1. After you've logged into StarBiogene, the left hand menu of the front page will contain a list of “modules” that are available for you to run. Modules represent the programs in StarBiogene available for you to run. Modules can actually process data (i.e. the modules prefixed with “process”) or simply view data (i.e. the modules prefixed with “see”).
  2. After selecting a module, a page will load containing the name of the module, a list of its parameters, and a run button. Fill in the parameters and click the run button to start the module.
    RESULT: A new page loads. After a few seconds, a visualizer application will pop up automatically and display the results.
  3. When you're done looking at the results, close the visualizer application to return to your web browser.
  4. Continue using StarBiogene by selecting another module if needed.
