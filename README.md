# STAR at MIT — static archive

This repository preserves a static copy of the public STAR website originally served at [star.mit.edu](https://star.mit.edu/). The archive is independent and is not operated or endorsed by MIT. Original ownership, credits, and license notices remain with their respective rights holders.

The source owner has authorized this full-site archive for republication. See [`ARCHIVE_NOTES.md`](ARCHIVE_NOTES.md) for capture scope, method, and known limitations.

## Viewing the archive

Open `index.html` from a local static web server or static hosting service. Some legacy Java/Web Start programs, authenticated services, feedback flows, and other server-backed interactions cannot run from static files. External services remain external.

## Deployment

The planned staging hostname is `star.bugaco.com`. The `star.mit.edu` hostname is a separate, conditional DNS change and may only be configured by an authorized MIT domain administrator after staging and TLS checks pass.
