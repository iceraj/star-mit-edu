How to start Linux version?

StarBiochem.bin file is bash shell script. When you execute it, it will unpack and start StarBiochem. StarBiochem requires Java Runtime to be installed on your system

How to start Windows version?

StarBiochem.exe can be executed. StarBiochem requires Java Runtime to be installed on your system.

How to start MacOS X version?

StarBiochem.zip should be decompressed. It will create StarBiochem application that can be executed. It requires at least MacOSX 10.5.
