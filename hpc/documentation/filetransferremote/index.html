Transferring Files to the StarHPC Remote Cluster

The following guides explain how to transfer files to the StarHPC remote cluster using FileZilla:

Windows

If you're on Windows, you can use FileZilla to transfer files to the StarHPC remote cluster.

  1. Download and install FileZilla for windows from here.
  2. Open FileZilla by going to Start → Programs → FileZilla Client → FileZilla.
  3. Once FileZilla opens, there will be a “QuickConnect” toolbar under the file menu. Fill in the $hostname, $username and $password from here. Fill in 22 for the port and press “QuickConnect”.
  4. After connecting you should see two file explorers side by side; one for your local machine and your home folder on the StarHPC remote cluster (ie /home/$user).
  5. You can transfer files to and from by dragging and dropping them to the appropriate file explorer.

Mac

Filezilla also has a mac version. Below are general instructions for installing FileZilla 3 on either an Intel or PPC based mac.

  1. If you are using an Intel Mac: Download FileZilla_3.0.5.2_i686-apple-darwin8.app.tar.bz2 from here.
  2. If you are using a PowerPC Mac: Download FileZilla_3.0.5.2_powerpc-apple-darwin8.app.tar.bz2 from here.
  3. Open the file by double clicking the icon on your desktop. The file should extract and put a red “F” icon on your desktop. Double click this icon to start FileZilla.
  4. Once FileZilla opens, there will be a “QuickConnect” toolbar under the file menu. Fill in the $hostname, $username and $password from here. Fill in 22 for the port and press “QuickConnect”.
  5. After connecting you should see two file explorers side by side; one for your local machine and your home folder on the StarHPC remote cluster (ie /home/$user).
  6. You can transfer files to and from by dragging and dropping them to the appropriate file explorer.

Linux

Filezilla also has a Linux version. Below are general instructions for installing FileZilla 3 in your home folder on Linux.

  1. Download FileZilla_3.0.5.2_i586-linux-gnu.tar.bz2 from here.
  2. Open a terminal and change directories to where you downloaded the file:
    cd /location/of/file/
  3. Next extract the file by running:
    tar xvjf FileZilla_3.0.5.2_i586-linux-gnu.tar.bz2 -C ~/
    This will create a FileZilla3 folder in your home folder.
  4. Change to the filezilla bin folder:
    cd ~/FileZilla3/bin
  5. Run filezilla:
    ./filezilla
  6. Once FileZilla opens, there will be a “QuickConnect” toolbar under the file menu. Fill in the $hostname, $username and $password from here. Fill in 22 for the port and press “QuickConnect”.
  7. After connecting you should see two file explorers side by side; one for your local machine and your home folder on the StarHPC remote cluster (ie /home/$user).
  8. You can transfer files to and from by dragging and dropping them to the appropriate file explorer.
  9. If at any time you want to remove FileZilla simply delete the FileZilla folder from your home directory.
