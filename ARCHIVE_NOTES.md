# Archive provenance and capture notes

- **Source:** `http://star.mit.edu/` and same-host pages/assets reachable from its links.
- **Capture date:** 2026-09-26 UTC.
- **Supplemental resource date:** 2026-10-01 UTC; 16 public resources were retrieved using the `https://web.mit.edu/star/...` mirror paths. The installer URLs redirected to `http://star.mit.edu/media/...` and were fetched over HTTP; the downloader followed the server redirects normally and did not disable certificate validation.
- **JNLP supplement:** On 2026-10-01 UTC, four additional launch files were retrieved from `https://web.mit.edu/star/media/uploads/star/jnlp/`: `hydro/StarHydro.jnlp`, `hydro/StarHydro_beta.jnlp`, `biochem/StarBiochem.jnlp`, and `biochem/StarBiochem3.jnlp`. Each request redirected to the matching `http://star.mit.edu/media/uploads/star/jnlp/` path and returned an `application/x-java-jnlp-file` response. The files are preserved as served; their internal codebases and JAR dependencies still refer to legacy remote hosts, so archiving the launch files alone does not establish that the applications can run from this copy.
- **JAR supplement:** On 2026-10-01 UTC, all 54 distinct JAR paths referenced by the eight archived JNLP launch files were retrieved from `https://web.mit.edu/star/media/uploads/star/jar/<directory>/<filename>` into matching local paths. Requests redirected to `http://star.mit.edu/media/uploads/star/jar/` and returned Java archive responses. The 54 files total 103,829,192 bytes (about 99.02 MiB); each was checked as a ZIP/JAR archive before inclusion. The JNLP files retain their original remote `codebase` and `href` values, and both Hydro launch files reference external Java3D JNLP extensions. These launchers have not been shown to run from the static archive.
- **Browser runtime (StarGenetics):** On 2026-10-01 UTC, `genetics/runapp.html` was changed from a JNLP redirect to an in-page launcher that runs the archived `genetics2` JARs with the third-party CheerpJ 4.3 Java runtime, loaded from `https://cjrtnc.leaningtech.com/4.3/loader.js`. The page's Linux redirect to the downloads page (`athena.js`) was removed because it does not apply to the browser runtime; the JNLP launcher link is kept. CheerpJ does not implement `Unsafe.getShortVolatile`, which Apache POI 3.2 reaches when reflecting on `static final short` record IDs, so `poi-3.2-FINAL-20081019-cheerpj.jar` was generated next to the original by `scripts/patch_poi_for_cheerpj.py` (clears `final` on 1,098 such fields in 248 classes and removes the now-invalid signature; no other class bytes change). The original JAR is unchanged and still used by the JNLP files. CheerpJ needs HTTP Range support; `scripts/serve_with_range.py` provides it for local previews. Verified locally in Chrome with a fresh profile: the app started, preloaded its workbooks, and opened *Fruit Fly Exercise 1 - Level 1*. The app's own online calls (version check, `https://star.mit.edu/` content) fail and fall back to bundled copies. CheerpJ's console banner identifies it as the Community Edition, which is limited to personal and non-business use; confirm that this publication fits CheerpJ's license terms.
- **Browser runtime (StarBiochem, StarORF, StarGenetics beta):** On 2026-10-01 UTC, the same change was applied to `biochem/runapp2.html` (`biochem2`), `biochem/runapp_beta.html` (`biochem3`), `orf/runapp.html` (`orf`), `orf/runapp_beta.html` (`orf2`), and `genetics/runapp_beta.html` (`genetics3`, with its own `poi-3.2-FINAL-20081019-cheerpj.jar` generated by the same script from a byte-identical POI JAR). All runapp pages now share `media/uploads/star/scripts/cheerpj_launcher.js`; each page lists the main class and JARs from its JNLP file. StarHydro was deliberately left on Web Start. Verified locally in Chrome with a fresh profile against `scripts/serve_with_range.py`: both StarBiochem versions loaded the *Deoxyhemoglobin (1A3N)* sample and rendered it in Jmol; both StarORF versions started, and the current version translated a typed DNA sequence in six frames; StarGenetics beta opened *Fruit Fly Exercise 1 - Level 1*. StarBiochem logs `Error adding H atoms` and `NumberFormatException` messages while loading 1A3N without visible effect; whether the desktop build logs the same messages was not checked.
- **Feedback closed:** On 2026-10-01 UTC, the feedback image buttons on the StarBiochem, StarGenetics, StarORF, StarHydro, StarMolsim, and StarHPC homepages were unlinked and greyed out, and the "Send Us Feedback" text links now show an alert that the archive no longer accepts feedback instead of opening `feedback.html`. That page's form posts to `http://starapp.mit.edu/cgi-bin/feedback/webfeedback.cgi`, which this static archive does not operate; `feedback.html` itself is kept as captured.
- **StarORF HTML version removed:** On 2026-10-01 UTC, `orf/runapp_html.html`, its `orf/runapp_html.js`, and the matching start link on `orf/index.html` were removed. The page only framed `media/uploads/star/html/orf/app2.html`, which is not in the capture, so it did not work in the archive.
- **Sitemap supplement:** On 2026-10-01 UTC, the 300 page URLs listed in `http://star.mit.edu/sitemap.xml` (`Last-Modified` 2016-01-05) that the link-following crawl had not reached were requested over HTTP, one at a time with a short delay; no request was redirected. The Google and Yahoo site-verification files listed in the sitemap were excluded, and `orf/runapp_html.html` was not re-added because it was deliberately removed (above). Of the remaining 299 pages, 296 returned 200 and were saved; 3 returned 403: `biochem/problemsets/Krey%C3%B2l/index.html`, `biochem/problemsets/star/biochem/problemsets/Krey%C3%B2l/index.html`, and `cluster/docs/0.93.1/TODO.html`. Same-host images, stylesheets, scripts, fonts, and linked documents (PDF, DOC, XLS, `.sgz`, text) that those pages and their new stylesheets reference were then fetched one level deep without following further HTML pages: 682 assets were added and 120 requests returned 403, mainly StarCellBio jQuery UI/Wijmo files and images, legacy StarCluster webfonts (largely 0.92 and 0.92rc2), and 14 images under a malformed `media/index.html/...` path. In total 978 files (296 pages, 682 assets) and 73,461,780 bytes (about 70.06 MiB) were added; the largest is a 3,820,494-byte PDF, so no file reached the 25 MiB limit. New sections include `bacteria/` (StarBacteria GWT client), `biogene/`, `CellBio/app/` and `CellBio/StarCellBio/` (StarCellBio prototypes and SlidesJS examples; the sitemap lists them under lowercase `/cellbio/`, and they were merged into the existing `CellBio/` directory so the archive works on case-insensitive filesystems), StarCluster documentation 0.91, 0.92, 0.92.1, 0.92rc2, 0.93, 0.93.1, and 0.93.2, earlier StarBiochem version, documentation, and problem-set pages, StarGenetics problem-set pages and applet pages, StarHPC documentation, and `mailing.html`. Only these new files were post-processed: same-host URL normalisation using the functions in `scripts/prepare_static_copy.py` (pure `#` fragment links were left unchanged), removal of 37 Donate buttons, the Archive ribbon on 295 pages (`map.html` is a script fragment with no `<body>` and has none), and closure of 3 feedback image buttons and 3 "Send Us Feedback" links as described above. `error.html`, the source's not-found stub that redirects to the homepage with status 200, was captured and then removed at the project owner's request because `404.html` now covers missing pages. Pages that depend on Java applets, JNLP, or remote services are kept as captured and do not work from this copy: `genetics/applet.html`, `applet2.html`, `applet3.html`, and `ike/applet3.html`, `biochem/runapp.html` and `jmol.html`, `biogene/runapp.html`, `hydro/runapp_lidar.html` (scripts on `starapp.mit.edu`), and the StarHPC pages that link to `starapp.mit.edu/cgi-bin/hpc/hpc.cgi`. Links on these pages to `starapp.mit.edu` were not rewritten. An audit of the 296 new pages, ignoring HTML comments, external links, and anchors, found 135 unresolved local references to 58 distinct targets. These include over-deep relative links in `biochem/documentation/version2.0/index.html`; 0.92-era StarCluster pages that are not in the sitemap; and the 403 responses above. The new stylesheets have 81 further unresolved `url()` references, mostly webfonts and jQuery UI images. Spot checks of 16 new pages and assets against the local preview server returned 200. Afterwards, at the project owner's request, the three `pirouette/` pages (a DokuWiki export whose stylesheets, scripts, and PDFs were linked only under `/star/...`, which returns 403) were removed; the page, byte, and unresolved-reference counts above include them (30 of the 135 references). The links in `biochem/documentation/version2.0/index.html` were then repaired at the project owner's request: 44 relative links that climbed above the site root were pointed at their evident `biochem/` and `biochem/documentation/` targets, and `media/index.html/...` image paths were corrected to `media/...`. The three screenshots that were still missing (`screenshot_starbiochem.png`, `search_results_protein_data_bank.png`, `structure_hetero.png`) were retrieved from `http://star.mit.edu/media/uploads/biochem/images/` (200), after which all 91 local links on the page resolve and all images loaded in Chrome.
- **Root files:** On 2026-10-01 UTC, `favicon.ico` (14,846 bytes) was retrieved from `http://star.mit.edu/favicon.ico`, and a new `404.html` was added, built from the `about.html` layout with root-absolute links and without analytics. Without it, Cloudflare Pages answered every missing path on `star.bugaco.com` with the homepage and status 200. `scripts/serve_with_range.py` now serves `404.html` with status 404 for missing paths, as Pages does; verified locally at a nested missing path. The source's `robots.txt` (`Allow: /`) was already archived unchanged. The source's `sitemap.xml` (3,989 `http://star.mit.edu/` URLs, `Last-Modified` 2016-01-05) was used for the supplement above but not added, because its URLs name the source host.
- **Capture status:** The initial mirror and linked-resource pass contained 5,131 files and 152,770,490 bytes (145.69 MiB). After adding 16 public resources on 2026-10-01, the publishable tree contained 5,147 files and 559,611,549 bytes (about 533.88 MiB), before the four JNLP files above were added; the largest asset is 102,597,759 bytes. The new installers exceed the 25 MiB per-asset limit noted for Cloudflare Pages, so this archive now needs a hosting plan that can serve those files or a deliberate decision to keep them outside that deployment.
- **Permission:** The project owner confirmed in this task that written permission for full-site republication is available. Keep the written authorization in the project records; this note is not itself that authorization.
- **Crawler guidance:** `robots.txt` returned `User-agent: * / Allow: /` at capture time.
- **Source freshness:** The homepage response reported `Last-Modified: Tue, 01 Dec 2015`; the capture records what the host served on the capture date, not necessarily recently edited material.
- **Transport limitation:** HTTPS currently presents a `*.cloudfront.net` certificate that fails hostname validation for `star.mit.edu`. The capture therefore used the same-host HTTP endpoint rather than disabling TLS certificate validation. HTTP does not provide transport encryption or server identity verification; this limitation is recorded for provenance.
- **Included:** Same-host HTML and static assets/documents (CSS, JavaScript, images, fonts, PDF, XML/text, JNLP, spreadsheets, and linked resources such as StarCluster source archives and mailing-list attachments), with local links converted for static browsing. Four explanatory HTML stubs mark 0.92rc1 pages that returned 403.
- **Excluded:** CMS/admin routes (`/star/`, `/admin/`), external services/pages, and file types outside the crawler allowlist. Most installers and compressed software packages were omitted from the initial crawl; 16 StarGenetics, StarBiochem, and StarORF assets, plus the visitor map and `athena.js`, were added on 2026-10-01.
- **Interactions:** The archive does not reproduce hosted applications, authentication, forms, or backend behavior.
- **Unavailable source paths:** The main crawl, targeted resource fetch, and legacy documentation recrawl received 29, 8, and 8 HTTP errors respectively; source responses included 403 denials, primarily legacy font files and older documentation routes. The unavailable 0.92rc1 examples, support, version, and license pages have clearly labeled archive notes; `/cluster/download.html` links to the available `/cluster/downloads.html` page instead. Decorative font assets unavailable from the source may use browser fallback fonts.
- **Static link review:** 3,967 HTML pages were checked at initial capture; the audit found zero unresolved local HTML links and zero remaining absolute links to `star.mit.edu`. On 2026-10-01, all 16 links into `starapp.mit.edu/star/...` were rewritten to local archive paths. 84 CSS files were checked; 92 unresolved CSS references are blocked font variants (mainly old EOT files and the 0.92rc1 font set).
- **Crawler artifacts:** Wget's literal filenames for query-string variants are ignored by `.gitignore` and stored outside the publishable tree; query links resolve to canonical static pages.

Original source pages and assets may retain their own separate credits and terms. This README does not replace the authorization or license terms that apply to individual materials.
