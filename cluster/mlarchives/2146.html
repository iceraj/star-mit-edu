Hi All,

StarCluster 0.95.4 has officially been released and is available for
download from the usual places:

http://pypi.python.org/pypi/StarCluster
/cluster/downloads.html

Version 0.95.4 of StarCluster is a bug fix release. The most significant
change in this release fixes a show-stopping issue for users launching
spot clusters on a default-VPC account without explicitly specifying a
VPC/subnet. It is recommended that you upgrade as soon as possible.

Please see the complete change log for more details:

/cluster/docs/latest/changelog.html#version-0-95-4

You can find the official docs for 0.95.4 here:

/cluster/docs/0.95.4

Please upgrade ASAP, test the new 0.95.4 release, and submit any bug
reports preferably to StarCluster's github issue tracker[1].

Thanks!!

~Justin

[1] https://github.com/jtriley/StarCluster
