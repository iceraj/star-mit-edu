Hi Alessandro,

Yes you can only stop an EBS-backed cluster. With that said any
cluster started with EBS-backed AMIs is stoppable provided it's not a
spot cluster. The latest StarCluster 11.10 AMIs are EBS-backed so if
you're using them with on-demand instances you can stop your cluster
using the 'stop' command and then restart them later on using:

$ starcluster start -x your_stopped_cluster

HTH,

~Justin
