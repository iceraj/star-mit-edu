Hi Fabrício

The bid price does not apply to the master node. Master nodes "always"
start as reserved (flat rate) instances unless you use the
"--force-spot-master" master.

Using the --bid flag with the start command is equivalent to setting a
SPOT_BID variable in your cluster template. This "bid" price applies to
worker nodes.
