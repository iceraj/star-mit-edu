I am attempting to configure StarCluster under Enthought's latest release with Python 2.7, but am getting a SignatureDoesNotMatch error when attempting to use EC2. I am able to spin up instances using packages in other languages with the access key information set in the StarCluster config file, so it is not an issue of having the wrong inputs.

From looking at previous mailing list posts, it seems that this may be an issue with how Python 2.7 reads unicode (http://mailman.mit.edu/pipermail/starcluster/2010-December/000575.html). The poster in the cited message downgraded to 2.6 to get StarCluster working, but I would like to stay at my the current version.

Is there a way to get StarCluster running on Python 2.7?
