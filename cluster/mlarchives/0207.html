Hi Andy,

Are you using StarCluster 0.90.1? When you say multiple clusters, are
you attempting to start two separate clusters (one after the other)? If
so, the current 0.90.1 version only supports launching a single cluster
at a time. Do you have issues even starting a single cluster?

The latest github version has multiple cluster support and should be
released soon. If you need this support before the release, I would
recommend testing the github version and submitting any issues you have
to the list.

The work-in-progress docs for the github code can be found here:

http://web.mit.edu/stardev/cluster/docs/

~Justin
