As far as I am aware, there is an option distinguish between the master
node and the compute node types. Hence, if you do not want the master node
to be a compute node as well, then there is no point in having such a
powerful master node.

I do not know if you can specify different instance types for compute
nodes. What is the motivation for this?

If you have different compute requirements for different jobs types, then
you could always setup two separate clusters with the required hardware
type.
