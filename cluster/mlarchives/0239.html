Jun-Wei,

Nope, I've added you, you should receive a subscription notice.

BTW, to fix the issue you have you can simply run:

$ starcluster stop volumecreator

This will remove the "volumecreator" security group from the output of
listclusters. This "volumecreator" group gets created when running
StarCluster's createvolume command and should be ignored. This is fixed
in github. Until I release a minor update you'll need to run that
command each time you run the *createvolume* command.

Hope that helps,

~Justin
