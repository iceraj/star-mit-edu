Thanks Lyn,

This does seem to resolve the issue and get the desirable effect! It worked well enough on a single test machine. Although I have not tested on the cloud.

For the sake of completeness for others reading the list let me explain your resolution.

Lyn noticed that weight_priority is set to zero by default on SGE. This means that the priority parameter in the -p option in qsub is ignored by the system by default. Therefore even if a job is released from dependencies it does not jump in priority like I wanted and just waits its turn in FIFO line - even if I asked for higher priority when launching the job.

Lyn proposed the following solution:
1. Retrieving the current configuration file
2. Modifying the weight_priority parameter in the configuration to allow the qsub -p priority to have influence
3. Loading the modified configuration file back to the system for the change to take effect

Lyn, you actually helped me fix something else related to this issue in my code - so double thanks.

      Jacob
