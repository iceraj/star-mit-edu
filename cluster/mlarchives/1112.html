Hi Eric,

Since you already have StarCluster installed you need to use the
--upgrade (-U) flag to upgrade to the latest version:

$ easy_install -U StarCluster

In general you can always install any version of a package using the
<package_name>==<version> syntax. For example,

$ easy_install StarCluster==0.93.2

HTH,

~Justin
