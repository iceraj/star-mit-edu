On 12/01/2010 11:42 AM, Alexey PETROV wrote:
> Sorry, I am very curious, how have you managed to prepare 'cg1/cc1
> instance types' once even 'canonical' team (the official
> Ubuntu distribution team) have not succeed in this yet?

I'm using the CentOS HVM AMI until Canonical/Alestic releases a proper
HVM image.

Creating an HVM AMI is more complicated than just rsyncing the files
from Ubuntu to a new volume, snapshotting, and then creating a new EBS
AMI from the snapshot. The kernel must be configured with the proper Xen
PV patches and I would bet this is pretty much the entire reason it's
taking so long to get a Ubuntu HVM image. I have attempted to rsync the
rootfs from Ubuntu and then copy the CentOS kernel over to skip the
kernel configuration/compile piece. The only problem with this is that
Ubuntu's init system requires a recent 2.6.30 kernel and unfortunately
the CentOS HVM kernel is 2.6.19. So I then started patching the latest
Ubuntu kernel with the necessary Xen patches, etc but could never quite
get the resulting AMI(s) to boot up. Even worse, I never got any console
output so it was a bit like shooting ducks in the cloud ;). So rather
than waste more time with this I decided to just use the reference
CentOS HVM AMI for now. I'll create a Ubuntu HVM AMI whenever
Alestic/Canonical figure out the kernel issues.

~Justin
