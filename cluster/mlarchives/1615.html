Hi Sergio,

This is expected behavior for the loadbalancer. You don't have any queued
jobs. Your job is in running 'r' state. Also notice the load balancer
reports

>>> Cluster was modified less than 180 seconds ago
>>> Waiting for cluster to stabilize...

This means that it will not make any decision since the cluster is not
'stable' enough. You need to wait a bit longer. You can change the metrics
the loadbalancer uses from the command-line.

Hope this helps,
Adam
