> I noticed in your crash report you're using the Amazon Linux AMI which
> is not compatible with StarCluster. You instead need to use one of the
> StarCluster supported AMIs. You can obtain a list of available
> StarCluster AMIs using the 'listpublic' command:
>
> $ starcluster listpublic
>
> To see AMIs in other regions:
>
> $ starcluster -r us-west-1 listpublic
>
> You will need to specify one of these AMI ids in your config file.
>
> You can also customize the StarCluster AMI for your needs:
>
> http://web.mit.edu/stardev/cluster/docs/latest/manual/create_new_ami.html
>
> Hope that helps,
