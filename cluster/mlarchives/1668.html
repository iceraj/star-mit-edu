I launched a cluster of cc1.4xlarge spot instances today using StarCluster. A placement group was successfully created, however only the Master node actually joined the new placement group. All child nodes were not in any placement group at all. I got no error of any sort, but this obviously defeats the purpose of having cc1 instances in a cluster if they are not in the same placement group. I tried the same thing with on demand instances and it worked, placing the master as well as the child nodes all in the StarCluster generated placement group as expected. When I launch a spot instance manually I am able to specify a placement group, so it seems that the functionality is available on Amazon's end, is there something I'm missing?
