The standard EBS-based StarCluster AMIs should be fine - I have never
encountered cleanup issues. Note that by default the root EBS volumes
are marked as "DeleteOnTermination", so when the instances terminate,
AWS automatically cleans them up.

Which AMI & StarCluster versions are you using, BTW??
