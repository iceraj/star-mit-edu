Hi Paolo,

Well it probably won't be the *next* version given that I need to put
out a patch release today/tomorrow but it should make it in to the next
major release.

As far as the config goes the only thing that will change vs using a
plugin to do this is that the cluster template itself would now support
a user_data option which would allow you to specify user_data in
multiple templates easily rather than having to create separate plugin
sections for each template in order to specify different scripts. We
should also add a command line flag to the 'start' command that
specifies a single user_data file to pass to all nodes in the cluster.

~Justin

> >>> The reason for storing the alias in user-data is that I needed some

> >>> somewhere in the middle - the nodes are guaranteed to be named the
> >>> same thing the next time around because of the user-data.
