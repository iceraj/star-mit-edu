Just following up on the list since we partly solved this on IRC. This
was an issue with PyCrypto 2.5 on OSX Lion. Downgrading to 2.3 seemed to
fix the issue but still not 100% sure why - pycrypto 2.5 works fine for
me on Snow Leopard 10.6.8...

Is anyone on the list able to run StarCluster on OSX Lion with pycrypto
2.5?
