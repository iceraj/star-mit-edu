Hi Liang,

My apologies for the delay. Moments ago I released version 0.92.1 which
supports running remote commands at command line using the sshmaster,
sshnode, and sshinstance commands. For examle, you could run a command,
say 'cat /etc/hosts', on the master node as root in a single line using:

$ starcluster sshmaster mycluster 'cat /etc/hosts'

See here for more details:

http://web.mit.edu/starcluster/docs/latest/manual/runcommands.html

Please upgrade and try out this new functionality. Let me know if you
have issues.

Thanks,

~Justin
