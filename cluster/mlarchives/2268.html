I believe it is cloud-init, which is installed by default on all the Ubuntu
AMI images, that is changing your password for the ububtu user.

So to verify, after you boot up an instance with your new AMI, get the
instance's console output by using the "Get System Log" action. If there is
a line like: Changing password for ubuntu, or anything related to password
in the boot log, then we can fix that for you by changing the cloud-init
behavior.
