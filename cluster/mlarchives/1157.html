Hi Boris,

Condor is only available on the StarCluster Ubuntu 11.10 AMIs. There's
a note in the docs about this:

http://web.mit.edu/star/cluster/docs/latest/plugins/condor.html

You can get a list of available StarCluster AMIs using the 'listpublic' command:

$ starcluster listpublic

HTH,

~Justin
