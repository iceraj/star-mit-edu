I suggest that the command "starcluster resizevolume" should refuse to make
a volume smaller, unless it is fixed to do something sensible in that case.
 The resize2fs command should probably work for this purpose but it would
have to be called in a different sequence than before, i.e. resizing
*before* taking the snapshot. Naturally this is a little more dangerous.
