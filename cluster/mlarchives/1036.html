Subbarao,

You're missing a required option in the config file. Open your
StarCluster config ($HOME/.starcluster/config) and search for
"t1-micro-trial-cluster". In that [cluster] section you are missing
'node_image_id' setting. This setting specifies the AMI id to use for
all worker nodes (also applies for master node if master_image_id is
not set).

HTH,

~Justin
