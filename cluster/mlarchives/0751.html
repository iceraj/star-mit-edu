Hi Folks,

Just a quick heads up about the wiki:

The old mediawiki-based site was turning into a major spam-fest so I
decided to ditch mediawiki in favor of github's git-backed wikis. This
puts the wiki more under my radar since I spend most development time on
github anyway and it's also nice to have the wiki and source code living
under the same roof. Hopefully this will eliminate the spam problem all
together.

So, I've migrated all of the AMI cookbooks to github and the old
mediawiki urls now redirect to StarCluster's github wiki. Contributing
to the wiki is as simple as signing up for github, logging in, and
navigating to StarCluster's github wiki page. From there you should be
able to edit and add pages as needed from your browser. When you sign up
for github to contribute to the wiki you're also automatically setup to
easily contribute patches to StarCluster's code base if ever needed.

With that said, please let me know if you encounter any issues using the
wiki or if old links are not redirecting properly.

Thanks!

~Justin
