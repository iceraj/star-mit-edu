Hi, A handy new AWS feature was released last week by my team and I. It
allows you to log your network traffic flows. When using AWS, i was always
curious about what my security groups were allowing/denying, but that data
was previously swallowed up.

Now you can expose it through CWL:
https://media.amazonwebservices.com/blog/2015/flow_see_a_stream_2.png .
Flow Logging can be enabled on a VPC, Subnet, or individual ENI.

If anyone uses it and has any feedback or feature requests, please send it
my way.
