> For that function to work (in 5.3.X or earlier), you *must* turn off
> ‘safe_mode’ in your php.ini file. See manual
> http://www.php.net/manual/en/function.shell-exec.php, and
> http://www.php.net/manual/en/ini.sect.safe-mode.php#ini.safe-mode for
> details on safe modes.
>
>
>
> Beyond that, you need to make sure apache user (or whatever you’re running
> as) has access to everything it needs. Be secure.
