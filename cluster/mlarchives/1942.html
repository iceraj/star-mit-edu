Hi Emillia,

Did you try pip install?

I recently installed the latest version of starcluster on windows 7 and I recall needing to switch between easy_install and pip install to get the installation done.

If you install anaconda or PythonXY for a python stack then you have pip as part of the tools installed and do not need to install it separately, you also get a bunch of libraries and a good python editor - Spyder and iPython as part of the installation.

I hope this simplifies the installation for you.
