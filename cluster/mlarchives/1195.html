Hi Justin,

Thanks for your response, fortunately I managed to fix it today.

Prior to responding to you I tried to start a cc2 instance manually (not using StarCluster) and encountered the same error, so the error was coming from Amazon. With a bit of digging I noticed that I was inadvertently using the us-east-1a availability zone. When I changed this to us-east-1c the instance launched.

So I corrected my StarCluster config file to use us-east-1c and the cc2 instances launched.

Btw to start the cluster I used "starcluster start -c harrycluster harryclusterCPU"

Harry
