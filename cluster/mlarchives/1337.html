Hi Håvard,

Unfortunately the Hadoop plugin doesn't currently implement the
on_add_node and on_remove_node methods which is why new nodes are not
configured to work with the existing Hadoop cluster. We need to
experiment with this and see what's required to add a node to the
cluster. I've created an issue to keep track of this:

https://github.com/jtriley/StarCluster/issues/131

If you have time to experiment with the steps needed to manually add a
node to the Hadoop cluster and then comment on the issue with the
necessary steps I can translate that to plugin code. Otherwise this
will need to wait until I have time to experiment...

~Justin
