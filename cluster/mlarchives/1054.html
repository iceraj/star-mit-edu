Hi David,

As you've already discovered, you must download StarCluster manually
without easy_install to get the completion scripts. The 'easy_install'
process does not handle installing shell-completion scripts given that
these are outside the scope of Python and are not really a part of the
StarCluster application/library - they're utility scripts that help
integrate your shell and StarCluster. They also do not have a consistent
install location across all OSes and always require a bit of
configuration before they work. I will make a note to update the
completion docs to mention the fact that the shell completion scripts
are not installed via easy_install and that you must manually download
and extract them.

HTH,

~Justin
