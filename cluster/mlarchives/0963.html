My apologies for the extreme delay on this. As you might have
discovered already the latest release includes new Ubuntu 11.10 EBS
AMIs which are now available in *all* AWS regions. This will be the
case moving forward for all StarCluster AMIs in the future. You can
see the available AMIs in any region using:

$ starcluster -r us-west-1 listpublic
