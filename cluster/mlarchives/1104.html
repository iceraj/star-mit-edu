Hi Robert,

Sorry for the delay - this one slipped past me. I've seen this issue
before but very rarely/randomly. Although it's ugly/annoying output,
everything has executed successfully - this error occurs once everything
has finished running and Python is attempting to shutdown.

This is most likely an issue within paramiko but could be related to
StarCluster not properly closing connections before exiting. On the
other hand, there are reports[1] that even when explicitly closing the
connection before shutdown this error can still occur.

With that said the next 0.93.2 version, which will be released later
today, uses the new actively maintained paramiko fork named 'ssh' so
we'll see if this issue shows up again after the switch and address it
then. For now please ignore this error and report it if you run into
this again after 0.93.2 has been released.

Thanks for reporting,

~Justin

[1] https://github.com/paramiko/paramiko/issues/17
