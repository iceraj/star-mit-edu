Hi Damian,

> Has anyone else noticed spikiness in the price for spot instances
> within the past two weeks.

Unfortunately I've only been using spot instances for development lately
so I'm not trying to keep them up for days at a time. I agree with
Austin your best bet is to up your bid. You'll still pay the same amount
(the current spot price) but you'll be more resilient to this spikiness.

> Do you know if there is any way to save the state of the cluster when
> a system halt signal is given by AWS?

Currently there is not, however, using EBS-backed instances would allow
you to save the instance's root partition and any data that was left.
You could then attach that volume to another instance later on to
recover the data.

I'm planning on adding EBS-backed AMIs to StarCluster and Fred Rotbart
has submitted patches that handle starting/stopping EBS-backed instances
including instances of the new cluster compute type (which you'll be
*very* interested in by the way given that you do lots of MPI). Stay tuned.

~Justin
