Yep, I use them all the time but only for StarCluster development where
I'm constantly starting/stopping clusters. However, even in these cases
you have to be careful. The instances run out of memory *very* easily -
using a ton of plugins can easily make them run out of memory and/or
drastically spike the CPU load. An interesting side-effect of using a
lot of plugins on a t1.micro cluster is that because the CPU is heavily
throttled the "load" on the system spikes very easily which can lead to
SGE/OGS jobs not being executed until the system load goes below the
SGE/OGS load threshold which can take between 5-10min. Just something
to keep in mind when using the t1.micro instance type...

~Justin
