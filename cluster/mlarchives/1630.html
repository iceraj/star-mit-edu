>

> PLUGINS = sge

>
> [plugin sge]
> setup_class = starcluster.plugins.sge.SGEPlugin
> master_is_exec_host = False
>
> You can also force the master to be a spot instance by using 'starcluster
> start --force-spot-master', which can save serious cash (90%).
