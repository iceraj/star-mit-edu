Hi Carlos,

Unfortunately there is no good manual way of doing this as of now. If
you want to change the size of the cluster, you have to *stop* the
cluster, change the cluster size, and start a new cluster. Restarting
with a different number of nodes and the -x option will not work.

Having the ability to add/remove nodes to an existing cluster is a
planned feature. The add/remove node functinality is also a requirement
for dynamically resizing the cluster based on the number of Sun Grid
Engine jobs. Dynamic resizing is also a planned feature for StarCluster.
This functionality will not make the next release but will be high
priority for the release following.

~Justin
