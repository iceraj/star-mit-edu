On 11/08/2012 01:06 PM, John St. John wrote:
> Hi Matt, I just helped a friend install starcluster on 10.8 and he
> had the same issue. What we did was to manually install GMP.
>
> 1) wget ftp://ftp.gmplib.org/pub/gmp-5.0.5/gmp-5.0.5.tar.bz2 2) tar
> xvzf gmp-5.0.5.tar.bz2 3) cd into the dir, then ./configure, then
> make -j4, then sudo make -j4 install
>
> Then starcluster should install without issues.
