I think StarCluster is able to handle it... internally, it uses AWS as
the storage for the configuration. As long as you provide the correct
cluster name, then it can find the cluster & the nodes of that
cluster.

If you stop the master (which you can as it is an EBS instance), you
should be able to "sshmaster" back it again.
