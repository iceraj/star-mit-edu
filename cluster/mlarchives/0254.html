Hi Dean,

This "Error reading SSH protocol banner" error is related to a
connection timeout issue. By default, the paramiko library will wait for
15 seconds for the SSH banner to be returned by the server. If no banner
is returned in 15 seconds, you get this error.

I've increased the banner timeout to 30s in the github version of the
code. This code will be released as 0.91.1 in the next couple of weeks.
That being said, you should be able to test my fix for this problem by
using the latest github code or simply copying ssh.py from the github
code into your site-packages.

If you could test this out, I'd greatly appreciate it.

Thanks,

~Justin
