top of starcluster AMIs. I have gotten errors trying to update packages,
I'm guessing because the last ubuntu release that there's starcluster AMIs

12.04 as my starting point.

that I use. I then image the instance to a new AMI so that I don't need to

sending along my script in case it happens to help.
