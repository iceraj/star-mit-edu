I checked with Rayson (Scalable Logic) a while ago, and the problem at that time was related to the security groups.

With security groups in normal EC2, the description can be unlimited in length. With security groups in VPC, it is finite.

There are also a few Boto issues (#561and #599) with VPC, but they were already fixed by Justin (MIT).

https://github.com/jtriley/StarCluster/issues/21

So VPC support is almost done or not that far behind. Also Rayson mentioned on this list that HP Cloud cannot have
security groups that have unlimited length for the description field.

 -Ron
