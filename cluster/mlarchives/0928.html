Hi Yisong,

This is happening because you're not using an official StarCluster AMI.
Looking at your crash report you're trying to use the cc1.4xlarge
instance type which requires an HVM/EBS AMI. You can obtain a list of
StarCluster AMIs using the 'listpublic' command. Running this command
you'll notice two HVM/EBS images are available:

$ starcluster listpublic
...
[4] ami-06a75a6f us-east-1
starcluster-base-centos-5.4-x86_64-ebs-hvm-gpu-hadoop-rc2 (HVM-EBS)
[5] ami-12b6477b us-east-1
starcluster-base-centos-5.4-x86_64-ebs-hvm-gpu-rc2 (HVM-EBS)

You should be able to use either of the above AMIs with the cluster
compute instance types without issues. After releasing the next version
(0.92.2) I will compile a new Ubuntu 11.10 HVM/EBS/GPU AMI that you can
also use...stay tuned.

Hope that helps,

~Justin
