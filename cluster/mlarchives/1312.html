They are ISO images, so you will need to convert them from ISO to KVM
(or Xen) image format. Also, OpenStack does not have its own VMM, so
if you are using KVM/QEMU (IIRC, KVM is the kernel part, so it's QEMU
that reads the image), then you will need to find the a way to convert
the ISOs to a format that KVM/QEMU uses.
