Hi Deepak,

This is a bug in boto 2.0b4 that should be fixed now in 2.0. I'm very
close to releasing an official 0.92 version which will use the latest
stable boto 2.0. Looking at the code for 2.0b4 I believe this is
happening because you have AWS_CREDENTIAL_FILE environment variable set.
If this shows up again, try unsetting the AWS_CREDENTIAL_FILE.

HTH,

~Justin
