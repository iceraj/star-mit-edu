Besides the others mentioned, AWS has their own "command line interface" CLI see here<http://docs.aws.amazon.com/cli/latest/userguide/cli-chap-getting-set-up.html> for installation instructions and here<http://docs.aws.amazon.com/cli/latest/> for usage.
