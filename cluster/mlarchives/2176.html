Hi All,

StarCluster 0.95.5 has officially been released and is available for
download from the usual places:

http://pypi.python.org/pypi/StarCluster
/cluster/downloads.html

Version 0.95.5 of StarCluster is a bug fix release with support for the
new R3 instance types.

Please see the complete change log for more details:

/cluster/docs/latest/changelog.html#version-0-95-5

You can find the official docs for 0.95.5 here:

/cluster/docs/0.95.5

Please upgrade ASAP, test the new 0.95.5 release, and submit any bug
reports preferably to StarCluster's github issue tracker[1].

Thanks!!

~Justin

[1] https://github.com/jtriley/StarCluster
