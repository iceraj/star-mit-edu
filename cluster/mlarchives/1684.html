Hi Federico:

Looks like you don't have permission (with the AWS info in your config) to create EC2 Key Pairs at Amazon. Are you using an IAM User account? Go to AWS, log in to the Management Console, go to EC2 > Key Pairs, try to create one there. If that works, there's something funky with your starcluster config file. If it doesn't work, and you're using an IAM User account, you'll need to get permission from the master account holder.

Hope that helps!

Cheers, Hugh
