Hi Alex,

Does this happen each time you try to start a cluster? I'm wondering if
this is a fluke network connection issue or if it's a repeatable problem.

There is also an issue with the latest version of paramiko used from
PyPI. Would you mind sending me the output of:

$ python -c "import paramiko; print paramiko.__version__"

I've developed against paramiko 1.7.4:

$ python -c "import paramiko; print paramiko.__version__"
1.7.4 (Desmond)

If you're using 1.7.5 you may want to try downgrading to 1.7.4
(http://www.lag.net/paramiko/download/paramiko-1.7.4.tar.gz) until the
author has released another version of paramiko to pypi. (remember to
remove the old paramiko first)

I will add a note to the documentation about this.

Thanks!
