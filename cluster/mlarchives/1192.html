Hey Sergio/Ron,

StarCluster automatically creates a placement group when launching any
cluster compute instance type. If the instance type is not cluster
compute then it's only launched in the cluster's security group and not
the placement group. So in short only your cluster compute instances
will be on 10GigE. Unfortunately at this time this means your master
node needs to be a cluster compute instance in order to share NFS over
the 10GigE network.

HTH,

~Justin
