Hi All,

I've released an extremely minor update to StarCluster on pypi as
version 0.90.1. This version is really only useful to new users since
the only real change is the AMI ids presented to new users in the
configuration template when they first try to use the software.

So, feel free to upgrade to StarCluster 0.90.1 if you want; it should be
identical to the 0.90 version.

Whichever version you use, please make sure to update your
~/.starclustercfg with the latest starcluster AMI's:

(x86) ami-8f9e71e6
(x86_64) ami-a19e71c8

I'm still waiting to hear back from Amazon about the previous
StarCluster public AMI's that were mysteriously deleted. I'll post to
the list again when I get a conclusive answer.

Thanks and again my apologies for any inconvenience.

~Justin
