Hi Subbarao,

The AMI you're using (ami-31814f58) is not supported by StarCluster.
Please use one of the StarCluster Ubuntu 11.10 AMIs when using the
mpich2 plugin. You can get a list of StarCluster supported AMIs using:

$ starcluster listpublic

HTH,

~Justin
