Hi All,

For those who'd like to try an alternative to Hadoop, Chris Mueller
has put together
a StarCluster image with Disco (an alternative, open source map-reduce system
from Nokia Research, more at http://discoproject.org/ ) and a plugin for it.
It's a great Python way into map-reduce.

The post to the disco group is here and it has the link to github and a link to
a video of Chris' talk at the PyData Workshop.

http://groups.google.com/group/disco-dev/browse_thread/thread/50d6d8de5cfce252

Don

PS: Although I helped with the plugin, my ability to help with Disco
may be limited.
