Hi Amirhossein,


You don't need to tear down a StarCluster and start a new one just to get qconf included in the path.

If the root (or any other user) shell does not include the SGE binary directory in the $PATH, you can source the setting.csh (csh/tcsh) or setting.sh (bash/sh) scripts (in the /opt/sge6-fresh directory) to pick up the PATH & other settings required for running SGE binaries.


If you can qsub, then qconf is already in your $PATH.
