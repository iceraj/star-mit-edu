Hi Jonathan,

Very strange - both AMIs work for me no problems. What version of
PyCrypto are you using? You can check this by running:

$ python -c 'import Crypto; print Crypto.__version__'

If it's not 2.5 I'd suggest upgrading PyCrypto and see if that solves
the problem:

$ easy_install -U pycrypto

Also, StarCluster keeps a log in ~/.starcluster/logs/debug.log which
might be useful in figuring out what the issue is.

I'm also on #starcluster on IRC (freenode) if you want to debug this in
real-time.

~Justin
