Hi Jian:

There's a problem with 0.95.5 with the latest version of boto package (https://github.com/jtriley/StarCluster/issues/455). Justin's working on an update, but in the meantime you can do:

pip uninstall boto
pip install boto==2.32.0

That should work!

Let us know your results.

-Hugh
