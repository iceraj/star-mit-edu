Hi All,

StarCluster 0.94.3 has officially been released and is available for
download from the usual places:

http://pypi.python.org/pypi/StarCluster
/cluster/downloads.html

The complete change log is available here:

/cluster/docs/latest/changelog.html#version-0.94.3

NOTE: This release is not compatible with currently active clusters
created with a previous release of StarCluster. Please terminate all
active clusters before upgrading to 0.94.3.

You can find the official docs for 0.94.3 here:

/cluster/docs/0.94.3

Please upgrade ASAP, test the new 0.94.3 release, and submit any bug
reports preferably to StarCluster's github issue tracker[1] or to this
mailing list.

~Justin

[1] https://github.com/jtriley/StarCluster
