Liang,

Short answer is you can't. This isn't a limitation of StarCluster but
of EC2. You must have a 64bit AMI to run 64 bit instances and likewise
for 32bit instance types.

The only exception is t1.micro instances given that they can be
launched with either 32bit and 64bit AMIs. However, t1.micro instances
give you virtually no compute power (1/2 a core and 500MB of RAM) and
are not particularly well-suited for cluster computing.

So you will either need to use 32bit instance types with your custom
32bit AMI or create a separate 64bit version of your AMI.

HTH,

~Justin
