This suggests that your spot bid isn't high enough to be fulfilled. You
can get more status info about your spot requests using the AWS console
or starcluster's 'listspots' command. Check the spot request's status
code and status message for more details. In any case you'll notice that
the spot request is still in an 'open' state which means it hasn't been
fulfilled and assigned an instance yet which is why StarCluster is still
waiting.

~Justin
