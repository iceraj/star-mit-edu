Besides the others mentioned, AWS has their own "command line interface"
CLI see here
<http://docs.aws.amazon.com/cli/latest/userguide/cli-chap-getting-set-up.html>
for installation instructions and here
<http://docs.aws.amazon.com/cli/latest/> for usage. AWS CLI provides
tools for accessing S3. If you don't want to use AWS CLI, there are many
SDKs available depending on programming language or platform see here
<http://aws.amazon.com/tools/>.

Good Luck.

Jennifer
