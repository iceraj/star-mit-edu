Hi Chandra,

You can safely ignore this error. This is a bug in the Python 'ssh'
library used by StarCluster and will be fixed in the next release of
the 'ssh' library (see https://github.com/bitprophet/ssh/issues/28).
Fortunately this error only ever occurs while the Python interpreter
is shutting down which means everything important has already finished
executing by then.

- From the looks of the output you successfully created a new ami
(ami-0520946c). Hopefully the next release of Python 'ssh' will remove
this transient error once and for all.

~Justin
