Hi Fran,

You can start a master node first and then add different types of nodes
later. You may setup the SGE to define the job allocation behavior among
these nodes.

-Jin

> I still don't know many of the features of StarCluster, and I would

>

> ...
>
> ------------
>
> Is this currently possible with StarCluster? I guess that I can
