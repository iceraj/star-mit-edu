Abhijit,

The 'root' user *should* work. How did you launch the instance? If you
used StarCluster then you should be able to login using:

$ starcluster sshmaster cluster-name-here

and even if you didn't, the following command should work for you
assuming you have the keypair used to launch the instance defined in
your StarCluster config file:

$ starcluster sshinstance i-9999999

where i-999999 is the instance id. If you don't know the instance's
id, you can use the following command to get it:

$ starcluster listinstances

Let me know if you're still not able to login.

HTH,

~Justin
