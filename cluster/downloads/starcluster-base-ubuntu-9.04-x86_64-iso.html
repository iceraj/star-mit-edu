Using the ISO Image

After you've downloaded and extracted starcluster-base-ubuntu-9.04-x86_64.iso.gz, run the following commands to login to the iso image:

$ sudo -i

(enter root password)

$ mkdir -p /mnt/starcluster-base-ubuntu-9.04-x86_64

$ mount -o loop /path/to/starcluster-base-ubuntu-9.04-x86_64.iso /mnt/starcluster-base-ubuntu-9.04-x86_64

$ mount -t proc none /mnt/starcluster-base-ubuntu-9.04-x86_64/proc

$ mount -o bind /dev /mnt/starcluster-base-ubuntu-9.04-x86_64/dev

$ cp -L /etc/resolv.conf /mnt/starcluster-base-ubuntu-9.04-x86_64/etc/resolv.conf

$ grep -v rootfs /proc/mounts > /mnt/starcluster-base-ubuntu-9.04-x86_64/etc/mtab

$ chroot /mnt/starcluster-base-ubuntu-9.04-x86_64 /bin/bash

If you'd rather not have to run these commands by hand (or remember them for that matter), you can download a simple script to do this for you (only tested on Linux). To use this:

$ sudo -i

(enter root password)

$ mkdir -p /mnt/starcluster-base-ubutu-9.04-x86_64

$ python /path/to/chroot_iso.py /path/to/starcluster-base-ubuntu-9.04-x86_64.iso /mnt/starcluster-base-ubuntu-9.04-x86_64
